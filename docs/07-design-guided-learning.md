# LingSight AI · AI 协作与工程评审协议

1. **需求先行**：每项功能明确实际用户场景、输入、输出、数据来源和成功条件。
2. **本人决策**：自己选择模块边界和接口；AI 可以给候选方案，但不能代替理解和验证。
3. **代码审查**：对 FastAPI 路由→Service→Tool→MySQL/Worker 完整调用链能独立解释；生成代码需复核依赖、权限、错误与资源释放。
4. **先测试再声称完成**：包含正常路径、坏输入、越权、超时、重复执行和业务数值对照。
5. **科研可追溯**：保留实验、数据、模型、指标版本；不让 LLM 自己计算统计显著性或编造引用。
6. **外部代码许可**：青戈脚手架及开源项目先检查 LICENSE、依赖许可证和再分发限制；禁止在公开仓库上传无权再分发的 ZIP、私人科研数据或密钥。
7. **文档只留单一有效版本**：README 为入口，spec/roadmap/progress 分工明确；过时内容可以归档，但原有业务代码不在未审计时清空。
