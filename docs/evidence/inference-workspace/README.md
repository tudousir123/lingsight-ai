# 视频推理接入：本机及 L3 工程验证

核查及运行日期：2026-11-10。该记录区分工程运行和研究人员确认，不作为模型精度或科学结论的验收证明。真实视频、候选标注、权重、用户凭据及推理产物仅保留在运行环境，不进入 Git。

## 已实现

- 新建私有独立仓库 `tudousir123/lingsight-inference`，从 animal-platform 抽取首帧、水池及标志物代码，并适配已有 mask 追踪代码；v9 在最终 mask 像素质心居中的裁剪上独立推理头尾，保留无 mask 与低置信帧。目标为用户指定的 SSH `62222` 主机 L3，单 GPU 串行。
- 任务与版本保存在 L3 用户目录 SQLite 与私有任务目录。视频根为只读 NFS；浏览受限于配置目录。候选必须经确认，才进入追踪；结果按任务版本保存，取消及中断支持按阶段重试，输入视频哈希和权重哈希用于核验。已确认缺隐藏平台标定也可追踪，平台事件及相关指标不生成。
- 平台源码中新增个人工作区鉴权网关、视频列表/预标注确认/任务与结果页面。L3 推理服务仅监听回环地址；经本机 SSH 隧道访问。为避免更改现有运行容器，本轮使用独立个人工作区预览入口 `127.0.0.1:5174` 与单独网关；正式平台镜像及发布尚未替换。
- L3 的首帧、池/标志物、v9 合并及独立关键点四份权重 strict load 成功；GPU 可用。两份 v9 权重从 A100 复制到 L3 的服务模型目录后校验完整 SHA-256；mark 使用用户确认的 `ac707e…` 版本。L3 独立环境使用既有只读包环境作为系统包来源，fastapi、uvicorn 及 imageio-ffmpeg 安装在新服务 venv；服务和现有虚拟环境隔离，但基础包仍是共享依赖，后续正式化需独立锁定及迁移验证。

## 验证结果

- 纯服务 `uv run --extra test pytest -q`：5 passed，覆盖受限目录、候选确认门禁、独立版本、取消、重启恢复、旧 attempt 结果拒收及 mask 列优先质心协议。
- 本仓库后端 `uv run bash scripts/lint.sh`：mypy、ty、ruff 与格式检查通过；推理/Agent 网关相关 pytest：10 passed。
- 前端 TypeScript 检查及独立目录 Vite 构建通过。Playwright 单 worker 执行推理和已有 Agent 工作区测试：8 passed；预标注编辑在轮询后保留并提交。首次并行运行曾因页面加载/超时失败，单 worker 重跑通过。
- 在 L3 用一条真实视频成功生成预标注候选；独立工程试验使用该候选直接作为临时测试输入执行后续阶段，并不代表研究人员确认。视频容器标称 2854 帧，OpenCV 解码 2853 帧，经 ffmpeg 独立解码核验为 2853 帧；追踪输出 2853 帧，其中 2848 帧有有效 mask；v9 输出 2853 帧，其中 2847 帧 head 达到有效条件；H.264 叠加文件 86142922 字节。数字是这次运行状态，不是准确率。
- 正式个人工作区中真实视频任务 `f303297d-1547-401e-9ba5-f3a751776258` 已完成预标注并保持 `waiting_for_review`；使用真实登录账号从浏览器打开独立预览，核实任务、候选图和确认控件可见。没有代替研究人员确认，结果复核及完整人工验收尚未完成。

## 待完成及限制

- 人工确认页面当前提供数值和多边形坐标编辑以及叠加预览，尚无鼠标拖拽标注工具。既有 mask/质心复用入口未实现，目前对所选视频重新追踪。
- 标注确认和结果核对通过工作区执行；上述独立工程试验不能代替人工检查。真实工作区从确认到完整结果的交互验收、不同场景模型精度，以及生产部署尚待完成。
- 标称帧数不同时使用 ffmpeg 再解码核实；如果独立解码不同，阶段失败并保留原因。叠加文件较大，目前没有分段实时预览和批量并行。
- 本机预览网关复用已有个人工作区运行配置；镜像、令牌和视频不入库。相关运行服务均与既有平台分开，未修改原始视频或科研数据库。
