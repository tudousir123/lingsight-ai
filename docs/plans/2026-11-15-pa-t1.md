# PA-T1 Personal Agent Identity and Persistent Environment Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Give each authenticated researcher one persistent personal Agent/environment across isolated tasks, exposed through the existing gateway and workspace.

**Architecture:** Agent SQLite owns an immutable personal-agent/environment record keyed uniquely by trusted platform user. New tasks bind to that record, while each task/run retains separate context and run directories; legacy rows remain unclaimed. A versioned capability plus current-user endpoint flows through the existing authenticated platform gateway; the workspace displays identity/readiness and fails closed for unsupported services.

**Tech Stack:** Node 24/TypeScript, SQLite, existing Engine injection and HTTP API; FastAPI/httpx, React/TanStack Query, Bun/Playwright.
