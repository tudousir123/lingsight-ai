# LingSight AI 开发路线

**当前阶段：M0 → M1。先使用云端大模型 API。**

| 阶段 | 实现 | 验收 |
|---|---|---|
| M0 | 脚手架审计与导入、环境配置、启动、最小测试 | 前后端均可复现启动、无第三方许可证/密钥问题 |
| M1 | Text-to-SQL：SQL 语义层、Schema Linking、只读执行、校验、错误恢复 | 20–30 个真实科研查询有人工基准；业务数值正确与安全测试 |
| M2 | 科研 RAG：文档解析、混合检索、Reranker、引文检验 | QA 回归集与引用核对 |
| M3 | 单主 Agent 统一调用 SQL / 统计 / RAG，Vue 展示 Trace / 图表 | 一条多工具完整科研问题演示 |
| M4 | 接入 CV 小模型、Tracking、批量 GPU Worker、行为指标 | 原视频→指标→自然语言→图文报告可复现 |

**执行规则**：逐阶段开发与验收；不因新框架/JD 推倒当前路线，不凭空填写测量数字。每个模块先明确契约、失败路径、测试，再让 AI 辅助实现。
