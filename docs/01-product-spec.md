# LingSight AI 产品与技术架构（V0.1）

## 核心目标
基于动物实验视频提供自动场景感知、鼠体 Mask/头尾 Pose、Tracking、可回溯行为指标，以及 SQL + 文献双知识源科研 Agent。

## 交付边界
- 第一范式：Morris 水迷宫。
- UI/基座：FastAPI 官方 full-stack-fastapi-template（MIT，React 前端），数据库适配为本机 MySQL（权威实验库 water_maze，见 ADR-0002 与 docs/08 Schema 审查）。
- Agent：一期使用云端 API；单主 Agent 通过 typed Tool 调用 SQL、统计、科研 RAG。
- 隐藏平台不可见时需元数据/校准输入，不能生成猜测坐标。
- 首次出现、首次入水、碰台、有效上台等事件分别定义并评测。

### 页面说明与操作流程

以下文字可用于产品说明书。主要页面与交互沿用已确认设计；异常状态为配套设计要求，尚未形成独立效果图。

**实验与视频管理。** 用户以实验为上下文集中管理视频，通过实验组、鼠号、训练日和处理状态定位记录。页面展示视频总数、待确认项与已完成项，并提供批量导入入口。待确认视频进入分析准备页，分析中的视频可查看进度，已完成视频进入单次分析结果页。列表中的动物信息同时包含实验组和鼠号，避免跨组鼠号混淆。首次进入且没有视频时，展示导入引导；导入失败时保留成功项，并明确失败文件及重试入口。

**分析准备。** 页面以视频画面为主体，右侧集中呈现自动识别结果、基准平台来源和起始帧候选。用户可在画面中调整水池与标志物，核对来自参考图或实验标定的基准平台，并通过时间轴与逐帧操作复核首次入水候选。坐标等精细参数默认收起；主要操作为“确认并开始分析”，辅助操作为“保存，稍后继续”。自动识别失败或结果不完整时，应保留可用结果，标出需要补充的项目，并提供重新识别或人工修正入口，不显示虚假的已确认状态。首次入水候选用于分析准备，不自动替代逃逸潜伏期的计时起点；不同事件仍按各自定义记录。

**单次分析结果。** 页面将原视频、轨迹叠加与关键事件定位放在同一工作区，右侧展示本试次指标、单位和计算口径，底部提供轨迹分布、空间热图和速度变化。用户可切换显示图层、定位事件帧、进入结果复核并导出数据或报告。厘米及厘米每秒等物理单位必须有有效空间校准支持；缺少校准或事件依据时，相关指标应显示不可计算及原因，不能填入零值或示例数值。推理完成与结果已复核分别展示，不能将计算完成直接视为科研质量已通过。

**实验统计与报告。** 用户按实验阶段、指标、训练日和实验组选择分析范围，查看学习曲线、组间分布及统计明细。页面显式说明统计单位、试次到动物的汇总方式、误差线含义及纳入范围，并可回查纳入试次。效果图示例先汇总同一动物当天试次，再计算组均值，以动物而非视频数作为组间样本单位。用户选择实验信息、统计口径、图表和明细数据后预览或导出报告。筛选后没有可用数据时展示空结果与筛选条件；缺失数据不以零值补齐。描述性图表不自动附加显著性结论。

## Text-to-SQL 设计
**输入**：实验 ID、自然语言、用户身份。
**步骤**：权限与意图识别 → 相关 Schema / 指标术语检索 → 查询计划 → LLM SQL → SQLGlot AST 校验 → 只读 MySQL 限时执行 → 数据粒度/空值检查 → 可复现的统计解释。
**领域语义层**：experiment、animal、group、trial、training_day、frame、metric；按真实数据库核实字段后才固定 Schema。必须定义“逐鼠-逐日-逐组”聚合口径。
**安全**：服务端账户只读；可查询视图/列白名单；LIMIT/执行超时/资源限额；脱敏、租户实验权限和审计。
**失败**：错误分型、有限次 SQL Repair，超过限制明确报告错误，不让模型编造结果。
**验收**：20–30 条真实科研 QA，与人工审核 SQL 和数值比对；另测越权、不可执行 SQL、错误统计粒度。

## 科研 RAG 设计
以 RAGFlow 为候选独立服务；测试真实论文 PDF 与实验手册，比较文档解析、标题/表格结构、Chunk、Metadata、BM25+Dense、RRF+Reranker；简单检索直接回复，多跳/证据不足时由 Agent 限定次数重检索并验证文献引用。
数据与文献分开：MySQL 存实验观测，RAG 索引存解释性知识；LLM 不能替代 Python 统计。
**验收**：Recall@K/MRR，文献引用支持率，证据不足拒答准确性，任务耗时和成本。

## CV 与推理
专用分割/关键点模型 + Tracking，输出 frame_id、mask/pose、置信度、轨迹、场景/模型版本。GPU Worker 与 API 解耦；任务支持明确状态与去重。评估 IoU/PCK、事件帧误差、端到端免手工操作比例。

## V1 暂不做
本地 V100 部署、多 Agent、复杂知识图谱、SFT/DPO/GRPO、完全自动论文结论推断。
