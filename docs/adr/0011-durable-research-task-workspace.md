# 以可持久化科研任务工作区承载 Agent 分析

2026-11-09 用户确认采用科研任务工作区：围绕同一个任务集中保存对话、数据引用、分析代码、图表和报告，数据浏览保留为任务可引用的入口。关闭网页后任务继续；服务中断时保留已完成步骤与产物，能够说明从哪里继续或重跑。选择这一形态而非纯消息附件或仅在看板中嵌入问答，是因为科研分析需要反复修改并回查结果依据。

任务状态与产物需要由平台持久保存，不能只依赖浏览器连接或 Pi 对话记录。恢复不表示透明恢复任意运行中的 Python 进程；检查点粒度、可重跑步骤及运行记录形式尚待设计。用户要求先展示简短计划，再自动查询、编写分析代码、执行和修正图表；分组、样本排除、缺失值及统计方法等关键口径不明确时再提问。

用户进一步确认：首期 Agent 与分析环境都在本机运行；经确认的科研知识组织为版本化 Skills，并复用确定性计算函数。允许未完成动物身份核验的数据先做视频级探索，报告注明映射状态；正式动物数、逐鼠汇总与组间结论要求先确认映射，不同批次默认分开。

本 ADR 记录已确认的产品和执行语义；任务状态枚举、存储方案、服务协议、并发与恢复实现仍待确定。没有实施服务或代码迁移。
