# 独立 Agent 仓库拥有科研任务及交付物

2026-11-09 用户确认：Agent 立即使用独立仓库，独立运行并管理自己的任务、步骤记录、Pi 会话关联、分析代码和交付物；LingSight 负责界面、用户入口和实验浏览，经 API 调用 Agent。此决定取代“同仓独立进程”的起步建议，以便其他客户端完整使用科研任务能力，而不依赖 LingSight 的页面或数据库。

代价是两个仓库需要维护明确的 API、事件和兼容版本；平台的数据库不再作为科研任务状态的唯一所有者。Pi 是 Agent 服务内部引擎，不把 Pi 会话文件格式直接作为对外平台协议。

首期交付可编辑 Markdown 报告与网页预览，以及 PNG/SVG 图表、CSV 明细、Python 代码和来源记录的下载包。现有实验浏览保留，专用 Text-to-SQL 与旧问答在新闭环验收后退出；本次未删除旧代码、创建 GitHub 仓库或迁移运行中的服务。建议新仓库名 `lingsight-agent`，具体目录结构与 API 见产品规格中的评审稿。
