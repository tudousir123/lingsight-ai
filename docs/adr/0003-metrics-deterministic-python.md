# 行为指标由确定性 Python 计算并落库（指标表），SQL 只负责检索

README 核心原则「视觉模型产生观测，确定性代码负责计算，SQL 负责检索结构化数据」的落地：M1 新建实验指标表，由 Python 从 frame_predictions 确定性计算（游泳距离、平均速度等），写入 MySQL；LLM 与 SQL 不负责推导指标。2026-10-12 第 2 轮选型确认。

## Consequences

- 首批只实现**定义与输入都可靠**的指标，且必须保留算法版本、单位与计算状态列；潜伏期等依赖事件判定的指标，先验证事件定义再入列（事件定义见 01-spec：首次出现/首次入水/碰台/有效上台）。
- 指标表是语义层一等公民：『各组平均游泳距离』类问题直接查指标表，而不是让 LLM 现场对 77 万行帧数据写聚合 SQL——既控制生成复杂度，也守住科研口径。
- 帧级原始数据仍可查询，但聚合统计的推荐口径在语义层指向指标表。
- 指标重算必须走版本化（算法版本列），与科研可追溯要求一致。
