# 行为事件采用几何判定口径，逃逸潜伏期按「首次出现→有效上台」定义

工单 #6（M1-T7）人机协作检查点：四个行为事件（首次出现/首次入水/碰台/有效上台）的判定口径与参数经实验负责人书面确认后，逃逸潜伏期方可入指标表（承 ADR-0003 的版本化纪律）。完整规则见 docs/10-event-definitions.md；本 ADR 记录决策与依据。2026-10-13 四项全部确认，检查点通过。

## 决策

- **首次出现**=首个 `status='ok'` 且中心非空帧（计时起点，对入水瞬间跟踪丢失稳健）；**首次入水**=中心首次进入池圆（本库视频含入水过程，独立事件）；**碰台**=身体 mask 任一像素首次进入平台圈（2026-10-13 用户裁决「mask 参与比较合适」，替代中心点口径——ok 帧必有 RLE，可复算性不降）；**有效上台**=中心在平台圈内连续停留 ≥0.5s（终点）。
- **潜伏期 = 有效上台 − 首次出现**；无上台 → NULL + `no_mount` 状态，不编造。
- **平台圈半径 46px**：依据 `probe_platform_metadata.notes`（2026-10-11 实验负责人澄清的虚拟靶区口径）；训练日沿用为待核验假设（`platform_positions.all` 行注记 r≈46±8）。
- 停留时长取 0.5s（用户 2026-10-13 决策；文献常用 1s，从宽记录在案，抽样核验后可校准）。

## Considered Options

- **停留 1s（文献常用）**：更保守，但用户选择 0.5s；两者只差一个参数，核验后可改（algo_version 隔离）。
- **碰台按中心点（本 ADR 起草时推荐）**：实现最简，但用户裁决 mask 参与——身体擦边接触先于中心进圈，更贴近「碰台」的科研语义；mask 覆盖率 100%（ok 帧必有 RLE），不牺牲可复算性。
- **头/尾关键点参与碰台**：对贴边爬台敏感，但头尾在部分 ok 帧缺失，牺牲可复算性——不采用。

## Consequences

- 事件实现为确定性 Python（与 ADR-0003 同纪律），潜伏期与四个事件时刻以独立 `algo_version` 入 `trial_metrics`；事件时刻（碰台/首次入水等）经抽样人工核验比对事件帧（docs/10 AC2），评测套件纳入的是潜伏期两问（黄金 SQL 可判分；事件帧误差属人工核验范畴，不进 SQL 判分）。
- 碰台的 mask 判定需解码 COCO 列主序 RLE（`coco_counts_column_major`）；解码器以库内 `mask_area_px`/`mask_bbox_*` 为验证锚（和/极值一致才算通过），并以 bbox 预筛避免全量解码。
- docs/09 延迟清单前两问（逐日潜伏期学习曲线、第 1 vs 5 天改善）进入评测套件。
- 抽样人工核验（N=10 分层）不一致时，先改 docs/10 再改代码。
