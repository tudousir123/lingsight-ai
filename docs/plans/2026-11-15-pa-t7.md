# PA-T7 Automatic Personal Preferences Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Save narrowly admitted stable preferences from real task instructions, recall them across the same owner's projects, and show authoritative content/source/use in the existing workspace.

**Architecture:** Independent Agent SQLite owns versioned memory records, immutable sources, source-processing ledger and run-use evidence. Mem0 OSS is a separately partitioned, rebuildable index, never an authority. A sanitized short-lived local process loads only one server-selected owner's active preferences; extraction uses a separate index hydrated from authority so rejected model output cannot pollute later extraction. No configured and explicitly authorized processors means no Mem0/model/embedding calls.

**Tech Stack:** Node 24 TypeScript/node:sqlite, Mem0 OSS npm candidate mem0ai 3.3.1 (Apache-2.0, actual installation verified), built-in SQLite vector store; existing FastAPI gateway and React Query workspace. No new hosted infrastructure.
