## 数据与几何基础

- 帧序列：`v_query_frame_predictions`（工单 #7 后）按 `frame_idx` 升序；`status='ok'` 且中心坐标非空的帧才参与事件判定；30 fps，`time_s = frame_idx / 30`。
- **平台圈**：圆心 = `platform_positions.plat_cx_consensus / plat_cy_consensus`（当日共识坐标）；半径 = **46 px**。依据：`probe_platform_metadata.notes`（2026-10-11 实验负责人澄清：「虚拟目标区按 0809t 有平台阶段位置 (约1501.7,622.6)，半径约 46px」）。训练期 0804–0808 与探测期为同一物理平台，训练日沿用 46px（**假设，抽样核验时一并确认**）。

- 距离均为像素欧氏距离：`dist(center, c) = SQRT((center_x-cx)² + (center_y-cy)²)`，边界含等号（≤）。

## 逃逸潜伏期（领域第一指标）

**潜伏期 = 有效上台事件时刻 − 首次出现事件时刻**（秒）。首次入水作为独立可评测事件记录（事件帧误差），不参与潜伏期计算。

边界情形（写入计算与指标表）：

- 全程无有效上台 → 潜伏期为 NULL，`calc_status='no_mount'`（试次失败也是数据，不得删除或编造）。
- 无 ok 帧 / 平台圈坐标缺失 → 对应 `calc_status` 防御态（模式随 ADR-0003 指标表既有防御态）。
- 入指标表走新 `algo_version`（如 `v1-platformzone-46px-mount500ms`），保留单位与口径可追溯；重算发新版本，不改历史行。
