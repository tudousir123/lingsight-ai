# 从 animal-platform 抽取独立视频推理服务

2026-11-10 用户在比较“通过 API 复用旧平台完整后端”和“抽取模型与推理代码建立新服务”后选择后者。新服务使用独立仓库 `lingsight-inference`，拥有推理任务、模型版本与产物，复用已有水迷宫预标注与追踪实现；LingSight 提供统一入口与人工核对，科研 Agent 后续引用结果。不把旧平台整套业务后端作为必须依赖。代价是需要为抽取后的能力明确任务持久化、GPU 执行、输入与产物契约，不能把已找到源码等同于服务已可用。

本轮验收范围为单个水迷宫视频的推理和人工核对，后续再贯通科研 Agent 的统计与报告。用户确认保留推理前门禁：自动生成追踪种子、水池和标志物候选，经人工确认或修正后才启动逐帧追踪；追踪后的人工核对独立记录。该决定扩展此前首个科研分析闭环之外的视频推理能力，不改变 ADR-0012 中科研 Agent 拥有科研任务与交付物的职责。

用户指定 SSH 端口为 `62222` 的机器作为首轮运行位置，先选择已有实验视频。各次重跑保留独立的模型版本、输入标注快照及结果，人工核对绑定对应版本；首轮不写入现有 `water_maze` 和 `water_maze_v3` 科研库。执行采用单 GPU 串行队列，关闭网页后继续，支持取消和按阶段重试：已确认预标注可保留，追踪中断重跑追踪，叠加视频失败可复用轨迹重生成；不要求逐帧断点续算。自动识别缺项时允许人工补齐，缺隐藏平台标定时仍可追踪，不产生依赖该标定的上台事件和指标。

用户进一步确认使用其 GitHub 账号下的私有 `lingsight-inference` 仓库；代码与测试入库，模型权重、视频、结果和凭据留在运行环境。首轮沿用 LingSight 个人科研工作区的授权范围，平台后端通过受限网络和服务凭据访问推理服务，不开放公共推理 API 或引入多用户隔离。

用户指定小鼠头尾使用 v9，并确认链路包括 mask 追踪与 v9 关键点：对已有的逐帧 mask 和质心可复用且记录来源，对新视频需先由分割追踪模型生成它们，再运行 v9。v9 不独立生成 mask 或完整轨迹；具体权重来源、对齐和环境兼容性仍需核验。

首轮池与标志物预标注使用 `62222` 机器上实际哈希为 `ac707e786d1da0f478e56e6803039130768fb247b7e8d20f260d7f3dec6ffb24` 的现有权重，并记录哈希和人工核对结果。该文件目录名与旧清单中的同名权重哈希不一致，不将它当作清单中另一版本。
